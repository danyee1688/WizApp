# WizApp
A discord application made for experimentation and fun, centered around wizardry. This project stems from the original Getting Started application provided by Discord.

## Commands
### Start
Start your journey as a wizard - setup your first wizard.

### Wizard
_Optional parameter: user_ <br/>
View your wizard, or somebody elses wizard.

### Adventure
Go on an adventure! Fight enemies you come across.

### Shop 
Buy loot crates to find items and learn spells.

### Duel
_Parameter: user_ <br/>
Challenge another wizard to a duel. A prompt will show up so the target user can accept the duel request.

### Arena
Start an arena for many wizards to join and fight each other in pure chaos. 

### Wiki 
_Parameter: entry_ <br/>
Look up information about a certain mechanic in Wiz.
